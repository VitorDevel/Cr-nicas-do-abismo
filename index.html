DADOS DO DESTINO

Sou iniciante — como funcionam os dados?

D20 decide se um ataque acerta.

  • 1 = falha crítica.
  • 20 = crítico.
  • O resultado recebe bônus de atributo.

Os demais dados são livres para treino.

  • 2d6 = dois dados de 6 faces.
  • +3 = modificador somado ao final.
  • Exemplo: 2d6 + 3.
Após vencer, escolha uma ação no acampamento. O próximo inimigo aparece automaticamente.
