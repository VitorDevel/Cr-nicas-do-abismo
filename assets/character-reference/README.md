# Character reference sprites

These transparent sprites are crops of the supplied concept sheets. Each design includes front, back, and side views for the open world and the character preview. The original sheets remain in the user's Downloads folder; the game uses these optimized WebP cutouts.

Class mapping: Warrior → Guerreiro/Fighter, Paladin → Paladino, Druid → Druida, Archer → Arqueiro, Mage → Mago, Assassin → Assassino, Ninja → Ninja or the Assassin's Ninja/Shinobi branch, Necromancer → Necromante, Tank → Tanque, Samurai → Samurai, and Berserker → Berserker. The exact sheet cutouts are shown in the character creator; in-game movement and attacks use the animated rig.
